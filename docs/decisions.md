## Helix Native as a render target (measured on the Windows laptop, 22 Nov 2026)

Measured in `C:\Users\userx\helix_stage`, full numbers in ``docs/first_session_report.md``. The plugin only runs on the laptop, not on the Linux machine.

- Helix Native loads headless in Python through pedalboard 0.9.26 and renders audio with no authorisation dialog. The plugin exposes only master input level, master output level, master bypass, snapshot index (1 to 8) and generic knob, switch and cc slots. There is no preset select and no per-block parameter. The plugin state is only saved from the running plugin and loaded back unchanged; it is never edited.
- **A block control bound to Knob 1 can be driven from Python.** Test preset FUZZ OCT TMPL: Boctaver (`VIC_PitchBoctaver`) then Triangle Fuzz (`HD2_DistTriangleFuzz`), Sustain bound to Knob 1. Setting `knob_01` from Python changes the output, and the same setting renders identically every time. From knob 0.2 to 1.0 the spectral centroid of a 110 Hz test note rises in order (193 to 290 Hz); knob 0.0 is out of order, cause not tested. Output loudness barely moves with Sustain.
- **After the state loads, Knob 1 starts at 0 and seems to override the Sustain value stored in the preset** (the as-loaded render equals knob 0.0, though the preset stores 0.83). Not tested further.
- **Snapshot switching from Python works.** In this preset snapshot 2 bypasses the Boctaver, and the 55 Hz sub octave of the test note disappears at snapshot 2.
- **A preset written by code loads through the plugin window.** A copy of the exported preset with Sustain changed from 0.830 to 0.200 and a new name opened with "Open From Disk" and showed Sustain 2.0. Loading into a library slot with the IMPORT button was not tested.
- **How a knob binding looks in exported JSON:** one entry in `data.tone.automation.@assignments`, for example `{"@max": 1.0, "@min": 0.0, "@param": "dsp0.block1.Sustain"}`. It carries no knob number; Knob 1 is presumably the first entry in the list (not tested with two).
- **Driving the editor window with computer use:** its pop-up menus ignore a quick simulated click but work with a slow press and release; closed dropdowns can be stepped with the mouse wheel. Ctrl+S does not save.
- **Consequence:** a Helix chain is built in the editor (by clicks, or as a code-written preset file opened there), its state saved once, and then only the controls bound to knob slots plus the snapshot can be changed from Python. Blocks cannot be chosen from Python.

- **The EQ is now calculated, not guessed (chain 4, `C:\Users\userx\helix_stage\fit_eq.py`).** Chain 4 is chain 3 plus a 10 Band Graphic EQ and three stacked Low and High Cut blocks after the cab. It measures what each band and each cut setting really does by rendering, solves for the settings that close the gap (least squares), then renders and measures again. Because the EQ comes after the amp, its effect adds exactly in dB.
